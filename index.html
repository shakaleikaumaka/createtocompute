05The Patronage Model

Compute is never zero — someone always pays the last few cents. So we bridge honestly:

  • Ruthless routing second — every call goes to the cheapest model that passes the heart-check.
  • Patronage pool third — a seed grant covers early creators: first 3 creative gifts free, then create-to-compute.
  • The river later — as the gift economy grows, a 3.69% flow split refills the pool. The token is the circulatory gift layer, not the electric bill.
